# 决定记录（decisions）

这里放任务卡和执行计划都没覆盖、需要人确认的决定。AI 遇到这类事时写一份记录，在 `PROGRESS.md` 的 `needs_human` 里加一条“待人确认：…”，然后停下问人（见 `AGENTS.md`“遇到不确定的事”）。

- **文件名**：`NNNN-简短标题.md`，编号从 `0001` 起按顺序递增，例如 `0001-留出区选择.md`。
- **每份写四部分**：
  1. **背景**：遇到了什么问题，为什么任务卡和计划没覆盖。
  2. **选项**：可行的做法，各自的利弊。
  3. **建议**：推荐哪个选项，理由。
  4. **状态**：`待人确认`，或 `已确认`（写明谁在何时确认，例如“已确认：张三，2026-11-05”）。
- 确认后不删记录，只改状态；如果决定被推翻，新写一份并在旧记录里注明。
