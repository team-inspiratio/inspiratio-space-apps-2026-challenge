## 看不懂的词

| 词 | 大白话 |
|---|---|
| 火点 | 卫星发现地面某一小块特别烫，就记一个点。火点不等于一场火 |
| MODIS / VIIRS | 老、新两代卫星相机。VIIRS 看得更细，同一片火数出来的点多好几倍 |
| 协调 | 把老相机的记录换算成新相机的尺度，让 2012 年前后能比较 |
| Aqua、Terra、S-NPP、NOAA-20 | 卫星的名字。前两颗带 MODIS，后两颗带 VIIRS |
| MALE | 我们的误差分数，越低越好。**不是准确率，不能说成“准确率多少”** |
| M1s | 简单比例法，用来对比的保底方法 |
| E028 | 最后选中的模型（两段式 LightGBM）：先判断有没有火，再估有多少 |
| 训练区 | 加州、科尔多瓦、南部非洲。模型用这三个地方学习 |
| 留出区 | 北澳大利亚、中西伯利亚、印度恒河平原。故意不给模型看，用来考试 |
| 测试 1 / 测试 2 | 测试 1：训练区 2012–2013 年。测试 2：留出区。都只考一次 |
| 冻结 | 文件锁定，只有人能解锁，AI 不能改 |
| 区间 | 换一批训练年份后估计会变动多少，**不是误差条，也不是置信区间** |
| ADR | 决定记录，放在 `docs/decisions/` |

### X2. 仓库是私有的，也没有 LICENSE 文件

- **一句话**：比赛条款要求团队原创内容可自由获取或使用开源许可，并要求引用全部来源；我们的仓库和 Release 现在是私有的，代码没有许可证文件。
- **可选方案**：
  1. 提交前把仓库改公开，加代码许可证（例如 MIT 或 Apache-2.0），数据保持 CC BY 4.0。

  3. 保持私有。
- **建议和理由**：选 1。条款的方向就是开放，改公开还能打开 GitHub Pages 这个部署选项。改公开前先由人检查一遍历史（密钥扫描 CI 一直是通过的）。选哪种许可证是团队的事。
- **不处理的影响**：评委打不开代码和数据，可能不符合条款。
- **关联**：[Participant Terms & Conditions](https://www.spaceappschallenge.org/legal/)；[ADR 0016](decisions/0016-部署方案对比.md)。

### 第 14 条：NOAA-20 接续算不算“连续”

- **一句话**：S-NPP 缺数据的月份用 NOAA-20 换算补上；通过标准是**看到检验结果之后**才提的，所以必须由人决定接不接受。
- **可选方案**：
  1. 接受建议标准：每个区月总量偏差中位数在 ±5% 以内，且至少 80% 的“区域 × 年”在 ±10% 以内。按此标准算通过（中位数 −0.3% 到 +3.1%，15 个里 13 个在 ±10% 内）。
  2. 不接受，换更严的标准或不宣称连续。
- **建议和理由**：选 1，同时对外只说“scaled NOAA-20”，不说 “seamless”。标准是事后提出的，这一点要如实写。
- **不处理的影响**：人决定之前，网页和项目页都不能宣称 NOAA-20 段是连续的。
- **关联**：[ADR 0005 第 4 条](decisions/0005-保底模型桥接接续与v0来源规则.md)、[`reports/scores-v1.md`](../reports/scores-v1.md) 第 5 节。
