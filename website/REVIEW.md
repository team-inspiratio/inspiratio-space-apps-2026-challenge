# V2 research interface review

Scope: map-first V2 refinement requested November 7, 2026. Published scientific models and anomaly calculations are unchanged. Custom-area overlap now supports the antimeridian. Work is on `design/v2-research`.

| Challenge objective | Implementation / remaining dependency |
| --- | --- |
| Harmonized monthly calendar | Full-width 2000–2026 grid, selectable months, explicit missing cells, annual totals requiring twelve complete months. Verified global-v1 release assets are loaded locally. |
| Region selection | Region menu and presets, draggable Leaflet map, wheel zoom, city labels, visible coordinate fields and left-button rectangle drawing. Custom areas automatically load intersecting global partitions rather than being restricted to the selected preset. Escape cancels drawing; Pan map restores ordinary dragging. |
| Specific time range | New month-level bounds scope the calendar, historical chart, table, CSV and PNG. Reference years for scientific anomaly classifications stay controlled by the separate reference-period setting. |
| Historical comparison | Existing same-month percentile, median, ratio, source and interval retained. Annual totals added. Current anomaly contract uses a median rather than an arithmetic mean. |
| Accessible visualization | Sequential teal and monochrome calendar ramps, high-contrast UI, larger text, reduced motion, persisted preferences, optional cell values and semantic monthly table. Keyboard arrows move between available cells. This is not a formal WCAG certification. |
| Download analytics / visualizations | Existing CSV and PNG now follow selected dates. CSV preserves source and quality flags. |
| Raw hotspot CSV | Release frontend assets contain aggregate monthly grids. Individual detection download needs separate approved point assets and remains unavailable. |

Verification: 37 scientific/export/geographic tests, browser checks for real samples, region changes, shared state, CSV/PNG, range filtering, preference persistence, keyboard and 390 px layout. Geographic checks cover ±180°, whole-world bounds, overlap weights, camera framing, mixed sources, partition selection and duplicate protection. Browser checks exercise wheel zoom, drag, coordinate entry, crossing areas, rectangle drawing, Escape cancellation and actual California/AUST/CEAM/Chongqing views. Synthetic released-data routes are confined to the browser test. They are never product data.

Data preparation uses the 21 required files already committed under `inspiratio-site/public/data/global-v1/`. Each file must match the tracked SHA256 manifest. A readiness marker enables the global catalog only after verification succeeds. Prepared copies stay in ignored `public/data/global-v1/`; preparation requires no credentials or external repository.

The map now draws the actual 0.25-degree cells for the selected month and reports hover values. Default map and calendar colors run from pale to dark red. Color-vision assistance is opt-in, with teal or monochrome palettes. Dates use explicit YYYY-MM text fields so browser locale cannot insert Chinese date labels. A Chinese-locale browser test checks English page content, actual data loading, monthly map changes and palette switching. The data loader handles both compressed and transparently decompressed server responses.

Local preview: `frontend-v2`, port 5176. Build retains the original release-loading contract and can load the complete verified release when prepared.

Map correction: every grid cell and the basemap use the same Web Mercator projection. The default camera fits the central 98% of detection weight independently on latitude and unwrapped longitude; this excludes distant low-count cells from camera framing only. Full coverage includes every supplied cell. Region totals are never filtered by camera position. A custom box is drawn only for an explicit coordinate selection and clips displayed grid polygons at its edges. West > east crosses the antimeridian; −180 to 180 covers all longitudes. Hover/click values describe the full source grid cell, while custom totals use overlap weights.

Map limits: street tiles and city labels require internet access and retain provider place names. Offline Natural Earth outlines remain available if tiles fail. Web Mercator displays latitudes up to ±85°; polar cells remain in totals. Custom selections load intersecting `kind=region` partitions, including the three holdout partitions, and exclude overlapping `kind=box` demonstration views. Loads are sequential, retain only intersecting cells, and fail visibly rather than returning a partial total. Sources and coverage flags are preserved; heterogeneous sources are labeled mixed. The camera remains fixed when switching months; Fit main activity reframes the selected month.

Chongqing diagnostic (November 7, 2026): the example rectangle [106 E, 29 N, 108 E, 30.5 N] is a study box near Chongqing, not an administrative boundary or an individual fire perimeter. It contains 48 released CEAS cells. August 2022 totals 420.03 VIIRS-equivalent detections, sourced from `noaa20_scaled`; the prior-August median is 62 across 21 reference years, giving 6.7747× and percentile 100 under the existing anomaly contract. August totals for 2018–2021 are 125, 68, 94, 62. The full CEAS August 2022 color maximum is 2,382.13 per cell, versus approximately 56 in this custom box, explaining part of the weak visual impression at regional scale. This is a consistency check of released aggregates, not independent validation of the fire event. No published counts, models or frozen inputs were changed. The event would need daily detection and burned-area evidence for an independent accuracy assessment. NOAA-20 continuity remains uncertain per docs/data-interface.md.
